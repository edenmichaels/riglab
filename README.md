# RigLab

**[⬇ Download RigLab 3.12.0 for Windows](https://github.com/edenmichaels/riglab/releases/latest)**

Click the link above, then under **Assets** click **RigLab-Setup-3.12.0.exe**. Run it to install RigLab.
You don't need anything else from this page. The rest is RigLab's source code.

RigLab shows how healthy your PC is, controls fans and RGB lighting, runs speed tests, adds an in-game
overlay, and lets you undo every change it makes. See [README.txt](README.txt) for what's new in each version.
